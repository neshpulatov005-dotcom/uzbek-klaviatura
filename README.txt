OʻZBEK KLAVIATURA (Ö Ğ Ş Ç) — Android loyihasi

A) Telefonning oʻzida (kompyutersiz), GitHub orqali:
 1. github.com da bepul akkaunt oching va yangi repository yarating.
 2. Shu zip ichidagi hamma fayl va papkalarni (.github papkasi bilan) repository'ga yuklang.
 3. Actions boʻlimiga kiring -> "APK" -> bajarilishini kuting (3-5 daqiqa).
 4. Tugagach, "uz-klaviatura-apk" artefaktini yuklab oling, zip ichidan app-debug.apk ni oching.
 5. Telefon "nomaʼlum manbalardan oʻrnatish"ni soʻrasa, ruxsat bering.

B) Kompyuterda: Android Studio -> Open -> shu papka -> Build > Build APK(s).

Oʻrnatgandan keyin: ilovani oching -> "Klaviaturani yoqish" -> roʻyxatdan yoqing -> "Klaviaturani tanlash".
